# Python Skill

You are working with Python code. Follow these guidelines:

## Code Style
- Use PEP 8 conventions for formatting
- Type hint all function signatures
- Prefer f-strings for string formatting
- Use `dataclass` for data structures

## Testing
- Write pytest-style tests
- Test edge cases and error paths
- Name test files `test_*.py`

## Package Management
- Check for existing `requirements.txt`, `pyproject.toml`, or `poetry.lock` before installing packages
- Prefer the project's existing dependency management tool
